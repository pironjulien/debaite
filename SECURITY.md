# Security policy

Please report suspected vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/pironjulien/debaite/security/advisories/new),
not in a public issue. Include the affected file or URL, the impact and the steps to reproduce.

## Disclosure

You will get a first answer within 3 days. A confirmed vulnerability is fixed in a new release, usually within 30
days, then disclosed in a GitHub security advisory that credits the reporter unless they prefer otherwise. Please
keep it private until the fix is out.

Only the latest version is supported.

Secrets, production credentials, local runtime files and generated deployment files must never be committed to this repository.
